# Global Cuisine

Global Cuisine is a responsive, multi-page website that explores the culinary traditions of five countries through recipes, cultural information, and interactive navigation.

Developed as a collaborative web development project, the website brings together food, culture, and technology to create an accessible and engaging experience for users interested in discovering international cuisine.

## About the Project

Global Cuisine was developed by a team of four, aiming to create cohesive website showcasing traditional dishes and recipes from our own countries (or any prefered country).

The project consists of over 25 interconnected pages, featuring content specific to every country, recipe pages, and a consistent navigation system.

As the project lead, I led the design and development of the website while coordinating the integration of individual team members' work to ensure a consistent user experience across all pages.

## Features

* **Explore International Cuisine:** Discover culinary traditions and recipes from five different countries.
* **Recipe Pages:** Browse dedicated pages featuring dishes from different cultures.
* **Responsive Design:** Layouts adapt to different screen sizes using CSS and Bootstrap.
* **Multi-Page Navigation:** Navigate seamlessly between country sections, recipes, and other website content.
* **Consistent User Interface:** Shared navigation, styling, and reusable page layouts provide a unified experience throughout the website.

## Technologies Used

* **HTML5:** Website structure, content, and navigation.
* **CSS3:** Custom styling, page layouts, and visual presentation.
* **Bootstrap:** Responsive grid system and reusable interface components.
